# Local font assets

Downloaded 2026-10-18 from the official Google Fonts repository:
- https://github.com/google/fonts/tree/main/ofl/dmsans : DMSans[opsz,wght].ttf, OFL.txt
- https://github.com/google/fonts/tree/main/ofl/dmserifdisplay : DMSerifDisplay-Regular.ttf, DMSerifDisplay-Italic.ttf, OFL.txt

The original, unmodified TTF files are served locally. The two accompanying SIL Open Font License texts apply. No request to Google Fonts is made at runtime. The static preview embeds these same files as data URLs. Local file names are shortened for deployment only.
