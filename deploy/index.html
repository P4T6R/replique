Réplique

L’atelier est installé sur ce serveur en accès privé. La connexion ChatGPT de cette version utilise un retour OAuth sur votre ordinateur.

Sur l’ordinateur qui ouvre ChatGPT, lancez cette commande dans un terminal et laissez-le ouvert :

ssh -N -L 127.0.0.1:8000:127.0.0.1:18081 root@replique.duckdns.org

Ouvrez ensuite Réplique sur cet ordinateur et choisissez « Se connecter avec ChatGPT ».

Si Réplique fonctionne déjà sur le port 8000 de votre ordinateur, arrêtez d’abord cette instance locale. Le tunnel nécessite un accès SSH au serveur.
