# Déploiement Docker

Le déploiement hébergé utilise la session ChatGPT privée du propriétaire,
des invitations et 20 crédits d’essai par compte Réplique. Voir
[HOSTED.md](HOSTED.md) pour la création locale de cette session, son transfert
chiffré vers le VPS, le domaine et les contrôles de démarrage.

Le parcours « Continue with ChatGPT » reste décrit dans [OAUTH.md](OAUTH.md).
Seul le propriétaire l’utilise en local ; il n’est pas servi par le domaine public.
